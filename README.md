# Linux System Health Monitor

A beginner-friendly Bash-based Linux monitoring tool that displays important system information and resource usage.

## Features

- Display hostname
- Display current user
- Display current date and time
- Display system uptime
- Display Linux kernel version
- Monitor memory usage
- Monitor disk usage

## Technologies

- Linux
- Bash
- Shell Scripting
- Linux Commands
- Git

## How to Run

```bash
chmod +x monitor.sh
./monitor.sh
